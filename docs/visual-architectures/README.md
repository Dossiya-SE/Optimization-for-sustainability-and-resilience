## Recommended use

Do not choose one diagram to replace all others. They represent different mathematical or research relationships.

```math
\boxed{
\text{Hierarchy}
+\text{Dependencies}
+\text{Cross-links}
+\text{Physical coupling}
+\text{Research logic}
+\text{Workflow}
}
```

Together they form the repository's visual knowledge system.

## GitHub-native principle

Every diagram in this directory is stored as source text. This gives:

- version control,
- readable diffs,
- reproducible rendering,
- direct links between equations and diagrams,
- no dependence on a proprietary binary diagram format.

Publication-quality figures can later be derived from the same conceptual architecture using TikZ, draw.io, Figma, or another graphics system while keeping these Mermaid files as the auditable source representation.
