# Resilience

Resilience models ask how an engineered system withstands, adapts to, and recovers from disruption.

## Canonical framework

The authoritative framework for the current Power–Transportation–Information–Organization study is documented in [`FINAL_FRAMEWORK.md`](FINAL_FRAMEWORK.md).

```text
Multilayer Structure
→ Causal Mechanisms
→ Coupled Hybrid Multiscale Dynamics
→ Feedback & Control
→ Viability
→ Resilience-to-Sustainability Transformation Interface
→ Sustainable Transformation Pathways
```

Stages 1–5 form the core resilience-analysis framework. Stages 6–7 translate resilience outputs into sustainable-transformation inputs and pathways without changing the core resilience model.

Core model dimensions:

- robustness,
- service loss,
- recovery,
- restoration sequencing,
- resource allocation under disruption,
- interdependent infrastructure.

The long-term goal is to connect physical system behavior to explicit optimization decisions.
