# Interdependent Infrastructure

Coupled infrastructure models require explicit mathematical links between sectors rather than narrative statements alone.

Examples include:

```math
\text{electricity availability}\rightarrow\text{water pumping capacity},
```

```math
\text{transport accessibility}\rightarrow\text{repair feasibility}.
```

A rigorous coupled model should identify:

1. sector-specific state or decision variables,
2. coupling variables or interface constraints,
3. direction of dependency,
4. physical units,
5. time scale,
6. consequences for feasibility and service.
