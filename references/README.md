# References

This directory stores bibliographic metadata and curated reading lists that support the mathematical models in the repository.

## Source discipline

- Prefer primary sources, textbooks, standards, and university course material.
- Record enough metadata to recover every source.
- Distinguish source-derived statements from new modeling assumptions.
- Do not redistribute copyrighted course files when permission is unclear.
- Cite the source of numerical coefficients used in case studies.

The first reading list is available in `reading-list.md`.
