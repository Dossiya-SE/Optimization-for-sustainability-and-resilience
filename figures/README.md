# Mathematical Visualizations

Figures in this repository should be mathematical objects first and decorative graphics second.

## Current visual sources

- `standard-basis/standard-basis.tex` — basis representation in $\mathbb R^2$.
- `flow-balance/production-flow.tex` — multi-stage production and sales balance.
- `build-visuals.tex` — compiles the current TikZ figures into one PDF artifact.

## Visualization standard

Every figure should identify:

1. variables,
2. axes or flow directions,
3. units when applicable,
4. mathematical relation illustrated,
5. correspondence with the equations in the associated model note.
