# Feasible Regions

Each linear inequality defines a half-space. The feasible region of a linear program is the intersection of the admissible half-spaces and the variable-domain restrictions.

```math
\mathcal F=\{x\in\mathbb R^n:Ax\le b,\;x\ge0\}.
```

Half-spaces are convex, and intersections of convex sets remain convex. Therefore an LP feasible region is convex.

## Two-dimensional interpretation

For two decision variables, each inequality defines a boundary line and an admissible side. The feasible set is the common region satisfying every constraint and the nonnegativity restrictions.
