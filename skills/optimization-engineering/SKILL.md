# Optimization Engineering — /op

## Trigger

When the user types `/op`, `/op here`, or `/op <problem>`, apply the Optimization Engineering Workflow defined in `/OP.md`.

## Goal

Solve optimization exercises by integrating:

- mathematical formulation and proof,
- exact geometry,
- engineering interpretation,
- computational verification,
- scientifically controlled visualization.

## Core pipeline

```text
FORMULATE → NORMALIZE → CLASSIFY → DERIVE → VERIFY
→ INTERPRET → VISUALIZE → COMPUTE → AUDIT → FREEZE
```

## Required gates

- G1 Mathematical
- G2 Geometric
- G3 Engineering
- G4 Computational/visual

Only freeze when all applicable gates pass.

## Authority

The full canonical rules, examples, worksheets, and visual ontology are in `/OP.md`. Do not silently replace or abbreviate that authority when performing a full `/op` run.
