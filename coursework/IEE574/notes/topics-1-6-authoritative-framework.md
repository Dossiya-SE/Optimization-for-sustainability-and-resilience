# 2. Topic 2 — Linear algebra is not background decoration

Topic 2 is the mathematical language behind Topics 4–6.

The course defines span as the set of all linear combinations, and a basis as a linearly independent spanning set.

The relevant chain is:

```math
\boxed{ \text{linear combination} \rightarrow \text{span} \rightarrow \text{linear independence} \rightarrow \text{basis} \rightarrow \text{rank}. }
```

For a matrix `A`,

```math
\operatorname{rank}(A)
```

is the dimension generated by its rows or columns, and column rank equals row rank.

This becomes critical later because:

```math
\boxed{ \text{basis in LP} = \text{linearly independent columns of }A. }
```

So when Homework 2 asks for **basic solutions**, Topic 2 is directly active.


Therefore, for hyperplane problems, we should reason using the dot product—not by visually guessing which way a vector points.

## The 10 formulation rules must become an audit checklist

The course explicitly introduces **10 Rules of Formulation**. Rule 1 requires clearly defining subscripts and sets; Rule 2 requires separating sets/indices, parameters, and decision variables.

The rules we should permanently enforce are:

1. **Define all sets and indices.**
2. **Separate indices/sets, parameters, and variables.**
3. **When describing a notation, include its indices.**
4. **Do not leave dangling subscripts.**
5. **Decision variables must appear meaningfully in the objective and constraints.**
6. **Decision-variable families should be linked when they describe one integrated model.**
7. Every index must either be **summed over or quantified**, but not inconsistently.
8. Keep the model linear when possible.
9. Avoid unnecessary Big-`M` formulations when possible.
10. Prefer disaggregated constraints when possible.

# 4. Topic 4 — the standard-form issue is now resolved

This is the most important correction.

```math
\boxed{ \begin{aligned} \min\quad &c^\top x\\ \text{s.t.}\quad &Ax=b,\\ &x\ge0. \end{aligned}}
```

```math
\boxed{ \begin{aligned} \min\quad &\sum_{j=1}^{n}c_jx_j\\ \text{s.t.}\quad &\sum_{j=1}^{n}a_{ij}x_j=b_i, &&\forall i=1,\ldots,m,\\ &x_j\ge0, &&\forall j=1,\ldots,n. \end{aligned}}
```

This appears explicitly on Topic 4, page 28.

So from now on, there is **no ambiguity**:

```math
\boxed{ \textbf{IEE 574 STANDARD FORM} = \min c^\top x \quad \text{s.t. }Ax=b,\;x\ge0. }
```

That is the definition we should use in Homework 2.

## Standard form versus canonical form

The next slide distinguishes **canonical form** from standard form. The course presents canonical LP forms such as

```math
\min c^\top x \quad \text{s.t. }Ax\ge b,\;x\ge0
```

or equivalently the maximization orientation

```math
\max c^\top x \quad \text{s.t. }Ax\le b,\;x\ge0.
```

The slides explicitly state that **standard form is needed for the simplex algorithm**, whereas canonical form is especially useful for duality.

Therefore we must stop using “canonical form” and “standard form” interchangeably.

# 5. The exact IEE 574 standard-form transformation protocol

Topic 4 gives us the authoritative transformation algorithm.

## A. Variable already nonnegative

If

```math
x\ge0,
```

leave it unchanged.

---

## B. Nonpositive variable

If

```math
x\le0,
```

introduce

```math
\boxed{x=-x',\qquad x'\ge0.}
```

---

## C. Unrestricted variable

If

```math
x\in\mathbb R,
```

the course explicitly replaces it by

```math
\boxed{ x=x^+-x^-, \qquad x^+,x^-\ge0. }
```

This is not an optional trick. It is the course's prescribed conversion.

---

## D. A `\le` constraint

For

```math
a^\top x\le b,
```

add a nonnegative slack variable:

```math
\boxed{ a^\top x+s=b, \qquad s\ge0. }
```

Topic 4 explicitly states that slack variables measure the remaining slack and must be nonnegative.

---

## E. A `\ge` constraint

For

```math
a^\top x\ge b,
```

subtract a nonnegative variable:

```math
\boxed{ a^\top x-s=b, \qquad s\ge0. }
```

The course example uses exactly this transformation.

We may call it a **surplus variable** for interpretation, while recognizing that the slides discuss the general use of nonnegative slack variables.

---

## F. Equality

If

```math
a^\top x=b,
```

leave it unchanged.

---

## G. Maximization objective

The course states

```math
\boxed{ \max c^\top x = -\min(-c^\top x). }
```

For a standard-form model, we therefore solve

```math
\boxed{ \min -c^\top x. }
```

The optimizer is unchanged; the standard-form minimum objective value is the negative of the original maximum value.

This is an important distinction:

```math
\boxed{ x^*_{\max}=x^*_{\min(-c)} }
```

but

```math
\boxed{ z^*_{\max}=-z^*_{\min(-c)}. }
```

# 7. Topic 5 — understand the feasible set before optimizing it

Topic 5 gives the geometry beneath LP.

A hyperplane has the form

```math
\boxed{ H=\{x\in\mathbb R^n:a^\top x=b\} }
```

with `a\neq0`, and `a` is the normal/gradient. If `x^0\in H`,

```math
H = \{x:a^\top(x-x^0)=0\}.
```

The two corresponding half-spaces are determined by

```math
a^\top(x-x^0)\le0
```

and

```math
a^\top(x-x^0)\ge0.
```

This is exactly the theory behind Homework 2 Problem 2.

---

## Polyhedron versus polytope

The course defines:

```math
\boxed{ \text{polyhedron} = \text{intersection of half-spaces} }
```

and

```math
\boxed{ \text{polytope} = \text{bounded polyhedron}. }
```

Therefore we should never decide “polytope or polyhedron?” merely by looking at the picture.

We prove boundedness or unboundedness.

# 8. Recession direction and extreme direction

This is especially important for Homework 2 Problem 3.

A recession direction `d\neq0` guarantees that, starting at a feasible point,

```math
x+\lambda d
```

remains feasible for every

```math
\lambda\ge0.
```

The slides emphasize that a bounded set cannot have a recession direction.

For

```math
X=\{x:Ax\le b,\;x\ge0\},
```

the course gives the equivalent homogeneous test:

```math
\boxed{ Ad\le0,\qquad d\ge0,\qquad d\neq0. }
```

For standard-form equalities,

```math
X=\{x:Ax=b,\;x\ge0\},
```

the condition becomes

```math
\boxed{ Ad=0,\qquad d\ge0,\qquad d\neq0. }
```

An **extreme direction** is a recession direction that cannot be represented as a strict conic combination of two distinct recession directions.

This tells us exactly how P3 must be solved:

```math
\boxed{ \text{derive recession system} \rightarrow \text{find cone generators} \rightarrow \text{prove they are extreme}. }
```


# 11. Extreme points are not automatically optimal

Topic 6 makes the precise statement:

> If an LP has an optimal solution with finite objective value, there exists an optimal solution at an extreme point of the feasible region.

That means:

```math
\boxed{ \text{some optimal solution can be an extreme point} }
```

not

```math
\boxed{ \text{every extreme point is optimal}. }
```

This corrects the earlier overly strong chain.

Our permanent chain is:

```math
\boxed{ \text{BFS} \longleftrightarrow \text{extreme point} }
```

and separately

```math
\boxed{ \text{finite LP optimum} \Rightarrow \text{there exists an optimal extreme point}. }
```

# 12. Basic solution and BFS — the exact course connection

Topic 6 makes the algebra–geometry bridge explicit.

For standard form

```math
Ax=b,\qquad x\ge0,
```

with `A\in\mathbb R^{m\times n}` having linearly independent rows:

a basic solution is constructed by selecting `m` linearly independent columns of `A`, setting all remaining `n-m` variables to zero, and solving the resulting equations.

A basic solution is a **basic feasible solution** if additionally

```math
x\ge0.
```

The course theorem states:

```math
\boxed{ x\text{ is an extreme point} \iff x\text{ is a BFS}. }
```

This is the exact mathematical foundation for Homework 2 Problem 4.3.

# 13. Generic BFS algorithm for any homework problem

The course's generic method becomes:

```math
\boxed{ \begin{aligned} 1.&\ \text{Convert LP to standard form.}\\ 2.&\ \text{Write }A,b.\\ 3.&\ \text{Determine }m,n\text{ and verify row rank}.\\ 4.&\ \text{Select }m\text{ candidate columns.}\\ 5.&\ \text{Check whether they are linearly independent.}\\ 6.&\ \text{Set nonbasic variables to zero.}\\ 7.&\ \text{Solve }Bx_B=b.\\ 8.&\ \text{If }x_B\ge0,\text{ it is a BFS.}\\ 9.&\ \text{Repeat for all candidate bases if enumeration is required.} \end{aligned}}
```

This is exactly the generic process introduced in Topic 6.
