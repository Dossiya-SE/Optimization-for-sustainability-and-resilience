# Power-Water Case Study

This directory will develop the first cross-sector infrastructure model before extending to power-water-transportation.

The minimum mathematical structure should identify:

1. power-sector variables and constraints,
2. water-sector variables and constraints,
3. coupling variables or interface constraints,
4. physical units and direction of dependence,
5. service requirements,
6. sustainability and resilience metrics.

A typical dependency is electrical power required by pumps and treatment assets. The coupling must be represented explicitly in the feasible set rather than only described narratively.
