# Contributing

## Mathematical quality checklist

Before merging a model or note, verify:

- [ ] Every symbol is defined before use.
- [ ] Every index has an explicit set.
- [ ] Parameters and decision variables are separated.
- [ ] Variable domains are stated.
- [ ] Units are dimensionally consistent.
- [ ] Each constraint has a physical interpretation.
- [ ] Objective units are clear.
- [ ] A small numerical or symbolic sanity check is included when useful.
- [ ] Figures use the same notation as the equations.
- [ ] Course-derived material is paraphrased and restricted lecture files are not redistributed.

## Preferred structure for model notes

1. Problem statement
2. Sets and indices
3. Parameters
4. Decision variables
5. Objective
6. Constraints
7. Compact formulation
8. Interpretation
9. Verification
10. Extensions
